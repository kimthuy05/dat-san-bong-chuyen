# HỆ THỐNG QUẢN LÝ LỊCH SÂN VÀ ĐẶT SÂN BÓNG CHUYỀN TRỰC TUYẾN

## 1. Giới thiệu dự án

Website quản lý và đặt sân bóng chuyền trực tuyến được xây dựng nhằm hỗ trợ khách hàng đặt sân thuận tiện và giúp Admin quản lý hoạt động đặt sân.

Hệ thống được phát triển bằng PHP và MySQL.

## 2. Công nghệ sử dụng

- PHP
- MySQL
- HTML
- CSS
- JavaScript
- Bootstrap 
- XAMPP
- Visual Studio Code

## 3. Các chức năng chính

### Khách hàng
- Đăng ký, đăng nhập và đăng xuất.
- Xem danh sách sân bóng chuyền.
- Xem thông tin và lịch sân.
- Đặt sân theo ngày và khung giờ.
- Gửi yêu cầu đặt sân ngoài giờ.
- Thanh toán tiền cọc.
- Xem lịch sử đặt sân.
- Gửi yêu cầu hủy lịch.

### Quản trị viên (Admin)
- Quản lý sân bóng chuyền.
- Quản lý lịch đặt sân.
- Xác nhận tiền cọc.
- Xử lý yêu cầu hủy lịch.
- Xử lý yêu cầu đặt sân ngoài giờ.
- Quản lý khách hàng.
- Theo dõi thông tin thanh toán và hoàn cọc.
- Thống kê hoạt động đặt sân.

## 4. Cài đặt và chạy dự án

1. Cài đặt XAMPP.
2. Sao chép thư mục dự án vào `htdocs`.
3. Khởi động Apache và MySQL.
4. Mở phpMyAdmin.
5. Tạo database có tên `dat-san-bong-chuyen`.
6. Import file SQL của dự án vào database.
7. Cấu hình kết nối database trong `includes/db.php`.
8. Mở trình duyệt và truy cập:

   `http://localhost/dat-san-bong-chuyen/`

## 5. Thành viên thực hiện

Dự án được thực hiện bởi nhóm sinh viên trong quá trình học tập và xây dựng đồ án.
